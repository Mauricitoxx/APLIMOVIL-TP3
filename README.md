### Tematica: Gestor de tareas con prioridad
  La aplicacion esta diseñada para completar tareas de diferentes areas, como tareas para el hogar, Facultad, etc. Donde cada tarea tiene una prioridad(alta, media, baja). 
Ademas cada tarea luego de realizarse se puede confirmar utilizando un checkbox,cuenta con un apartado, para, en caso de que haya sido registrada de forma erronea, pueda modificarse tanto el nombre, como la descripcion o 
la prioridad.
